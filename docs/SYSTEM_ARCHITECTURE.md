# METRICHECK System Architecture

METRICHECK is a comprehensive, adaptive field-inspection platform built to evaluate compliance with the Legal Metrology (Packaged Commodities) Rules in India.

## End-to-End Pipeline

1. **Capture**: Package images are captured via the cross-platform Capacitor frontend (Mobile/Web).
2. **Adaptive Inspection / Smart Camera**: Employs client-side ML Kit and dot-matrix preprocessing to identify clear labels locally.
3. **OCR + YOLO + QR/Barcode**: Backend/Edge extraction pipeline combining edge OCR and eventual backend YOLO spatial layout.
4. **Evidence Fusion**: Merging raw spatial bounds with semantic text labels.
5. **Product Intelligence**: Contextual categorization (e.g., Food, Biscuit, Imported) generated by Gemini teacher fallback.
6. **Rule Applicability**: Deciding which clauses of the Legal Metrology rules apply to the product context.
7. **Declaration Intelligence**: Mapping identified text to Legal Metrology specific declarations (MRP, NET_QUANTITY, etc).
8. **Spatial Intelligence**: Determining if declarations are grouped logically (e.g., principal display panel compliance).
9. **Physical Measurement**: (Future integration) Incorporating scale weight, volume, or font-size metrics.
10. **Deterministic Legal Engine**: Hardcoded backend logic assessing Rule Applicability against Declaration Evidence.
11. **Selective AI Recovery**: Calling Gemini strictly as a fallback when deterministic logic encounters ambiguous / unreadable OCR.
12. **Compliance Assessment**: Scoring violations vs. verified declarations.
13. **Evidence/Provenance**: Logging exactly where evidence originated (Edge, Gemini, YOLO).
14. **Inspector Decision**: Manual confirmation via UI (`POST /api/scans/:id/decision`).
15. **Audit/History**: Final commit to PostgreSQL database.
16. **Offline Queue/Sync**: Seamless Capacitor local persistence for offline scanning, syncing queued payloads when network returns.

## Technology Stack
- **Web/Android/iOS**: Single codebase React 18 + Vite running natively via Capacitor 8.
- **FastAPI**: Synchronous/Asynchronous Python backend orchestrating compliance logic.
- **PostgreSQL**: Relational storage mapping Audits, Products, and Inspector Decisions.
- **Model / Data Pipeline**: Scaffolding exists in `ml/vision_intelligence`. 
- **AI Tooling**: Gemini currently acting as a "Teacher/Recovery" model to bootstrap datasets, destined to be replaced/augmented by local YOLO models.
